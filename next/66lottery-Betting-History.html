Betting History

Q : How can I see the history of the bets I made?
A : Hello, please click Account and select Game History My game history to check the bets on the games you have participated in. Thank You

Q : What is game history used for?
A : For game history, use it to check your activity bet on all the games you play on 66 Lottery, and for lottery, you can see all the detailed bet records you do on that menu. For 3rd-party games, if you want to see all the detailed records of betting, you must check it directly inside the game. 

API games take about 5-30 minutes! to return to history
